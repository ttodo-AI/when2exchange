# Track savings — 신호대로 환전했으면 얼마 아꼈나 (모트의 '증명')

## 목적
[[track-record]]가 매일 쌓는 신호 로그를 **돈으로 환산**한다. 적중률(맞췄나)이 아니라
**비용 비교**로 본다(사용자 요청):

- **스마트**: 빨간불(BAD) 피하고 초록·노란불(GOOD·NEUTRAL) 날에 나눠 환전 → 평균 단가
- **무신호**: 빨간불 아무 날에나 한 번에 환전 → 평균(전형)·고점(최악) 단가
- **차이 × 환전 금액 = 절약액**

이게 docs/MARKETING.md §3 모트의 "증명" 콘텐츠(인스타·앱의 "이만큼 아꼈어요")의 근거다.

## 실행 스크립트
`executions/track_savings.py`

```
python executions/track_savings.py                 # 공통(base) 신호 기준
python executions/track_savings.py --persona student   # 유학생/투자자/여행자 가중치
```

## 입력 / 출력
- 입력: `output/track_record.jsonl` (track_record.py가 매일 누적)
- 출력: 사람이 읽는 비교 리포트(stdout) — 신호별 일수, 스마트 vs 무신호 평균 단가,
  금액별($500/$1,500/$3,000) 절약액, 한 줄 요약.

## 정직성 원칙 (중요)
- 이건 **백테스트(과거 21년 전략검증, `backtest.py`)가 아니다.** 시작일(2026-06-12)
  이후 **실제로 쌓인 라이브 기록**에 대한 사후 비교다.
- **표본이 작을 땐 단정하지 않는다.** 30일 미만이면 경고를 같이 출력. 데이터가 쌓일수록
  신뢰도가 올라간다(모트의 본질 = 시간이 만든 증명).
- 결과를 보고 신호 알고리즘을 바꾸지 않는다(사후조작 방지).

## 좋은 결과의 모습
- 빨간불이 많은 구간일수록 스마트의 절약액이 커진다(직관과 일치).
- 페르소나별로 약간 다른 절약액(가중치 차이) — 셋 다 합리적.
- 예) 2026-06-12~29(12일): 노랑 분할 ~1,515원 vs 빨강 한 번에 ~1,538원,
  $3,000 기준 약 67,000~89,500원 절약.
