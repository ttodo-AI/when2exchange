# when2exchange 🐶

**매달 환전하는 사람(유학생·해외주식 투자자·여행자)을 위한 "지금 환전해도 될까?" 페이지.**

원/달러 환율이 1원 오르면 *내 월세·커피값·투자금*에 얼마가 더 드는지 한눈에 보여주고,
지금이 환전하기 좋은 때인지 **매력도·흐름·일정**으로 알려줍니다.

🔗 **라이브:** https://ttodo-ai.github.io/when2exchange

## 무엇을 보여주나
- **환전 매력도 게이지** — 최근 흐름에서 지금 환율의 위치 (페르소나별 가중)
- **체감 비교** — 어제보다 / 평소보다 이만큼 더·덜 (월세·커피·주식 1주 등)
- **환율 흐름** 차트 (1주 / 1달 / 3개월)
- **이번주 환율 영향 일정** — CPI·FOMC·금통위 등 D-Day
- **30초 요약** + **오늘 환율을 움직인 요인 Top 4** (뉴스 근거)
- **매달 환전한다면** — 오늘 상황에 맞는 조언 + 분할 환전 예시

## 어떻게 동작하나
- **정적 HTML 한 파일** (프레임워크 없음) — `executions/share_page.py`가 생성
- **GitHub Actions**가 하루 2회(아침 full · 저녁 light) 자동으로:
  환율(네이버)·주가(야후)·뉴스 수집 → 분석 → 페이지 빌드 → **GitHub Pages 배포**
- 무료 데이터 소스, 서버 없음, 모든 수치는 실측 기반(과장·추측 금지)

## 구조
```
directives/   각 워크플로우가 "무엇을" 하는지 (마크다운)
executions/   "어떻게" 하는지 (독립 실행 파이썬 스크립트)
site/         빌드 결과 = 배포되는 페이지
```
자세한 동작·규칙은 [CLAUDE.md](CLAUDE.md) 참고.
